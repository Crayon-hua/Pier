# Pier 界面优化与视频

设计方向：沉稳、准确、直接的部署值班台。保留 Pier 名称、蓝色品牌、页面顺序和已有业务能力。

## 界面调整

1. 间距：以 4px 为步长统一卡片、标题、项目行与导航，侧栏宽度统一为 240px。
2. 配色：灰白中性背景，蓝色用于主要动作；成功、失败等状态保留语义色，提高辅助文字对比度。
3. 图标：沿用 Arco 图标集，项目类型图标统一为中性色；移除统计卡片装饰图标。
4. 文案：以“应用部署概览”等实际页面上下文替换营销式标题，保留部署成功不等于持续健康监控的说明。
5. 字体：沿用系统字体，正文与标签 12–14px，标题 28–32px，数字采用等宽数字。
6. 布局：保留统计、项目、主机、任务的顺序；手机端改为带文字的底部导航，修正登录页横向溢出。
7. 细节：统一圆角、版本字号、表格留白、选中状态与键盘焦点。
8. 视觉：登录页以“选包、发布、检查与回退”的真实流程替换立体方块；未生成额外图片。
9. 动效：移除卡片悬浮位移，交互仅改变颜色与边框，并支持减少动态效果设置。

- `media/pier-intro.html`：自包含的介绍分镜源文件。浏览器打开后，用 `?slide=0` 至 `?slide=5` 查看六个分镜。
- `media/pier-refinement.html`：自包含的优化过程源文件，使用 unslop 的 `scripts/story.mjs` 重新渲染。
- `pier-overview.png`、`pier-login.png`：最终页面截图。

演示中项目、版本和任务均为浏览器请求拦截提供的示例数据，视频已标注。没有向真实服务器创建项目、发布版本或写入演示数据；生产页面继续调用现有 API。

## 验证

- Vue / TypeScript 生产构建通过；保留现有 Arco 分块大小提示。
- 概览、项目、详情、任务、设置共五个路由，在 1440px、768px、390px 下通过页面和横向溢出检查。
- 验证项目搜索、类型筛选、新建项目抽屉、发布版本弹窗及空状态。
- 登录页桌面和手机布局通过，无浏览器运行时错误。
- 两份 MP4 全片解码通过，并抽取开头、中间和结束画面做视觉检查。
- 本次未修改后端，未执行真实部署和回退操作。
